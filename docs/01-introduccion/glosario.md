# Glosario

| Término | Definición |
|---|---|
| **SGT-SIAAF** | Sistema de Gestión del Trámite de Titulación integrado al Sistema Académico, Administrativo y Financiero |
| **Expediente** | Unidad de trabajo del trámite (`ExpedienteTitulacion`); numeración `EXP-AAAA-NNNN` |
| **Providencia** | Numeración del expediente al enviarse formalmente: `PROV-AAAA-NNNN` |
| **Providencia 590** | Informe de aptitud legal emitido por Secretaría-Abogacía (`PROV-590-AAAA-NNNN`) |
| **Memorando 162** | Declaratoria de aptitud firmada por el Decanato (`MEM-162-AAAA-NNNN`) |
| **Petición documental** | Solicitud atómica de un requisito del Art. 235 dentro de un expediente |
| **Checklist** | Verificación digital por requisito a cargo del jurista (`ChecklistVerification`) |
| **Observación accionable** | Motivo formal que bloquea un requisito y pausa el plazo; se cierra con una subsanación |
| **Subsanación** | Nueva entrega del documento (versión N+1) que atiende una observación |
| **Plazo de atención** | 8 días hábiles desde el envío formal (COA Art. 160); pausa al observar y reanuda al subsanar |
| **RBAC** | Control de acceso basado en roles; matriz de mundo cerrado (celda vacía = denegado) |
| **Ámbito (scope)** | Filtro de datos por rol: `own`, `carrera`, `facultad`, `asignado`, `borrador`, `allow`, `deny` |
| **IDOR** | *Insecure Direct Object Reference*; en SGT-SIAAF se mitiga devolviendo 404 ante objetos fuera de ámbito |
| **SGA** | Sistema de Gestión Académica institucional (simulado en Fase 1) |
| **FirmaEC** | Servicio ecuatoriano de firma electrónica (simulado en Fase 1) |
| **FL-01…FL-05** | Flujos funcionales de la especificación: crear, enviar, verificar/observar, subsanar, resolver |
| **Art. 235 RRA** | Artículo del Reglamento de Régimen Académico de la UNL que define los requisitos del trámite |
